f:Tff2,# 免费或促销提供商访问

一些第三方提供商可能提供试用额度、促销额度、订阅内权益，或暂时不按请求直接收费的访问方式。
Potluck 可以连接受支持的服务，但这些权益并非由 Potluck 提供或控制。

## 不承诺永久免费

不要假设某个提供商、模型、配额或认证入口永久免费或无限量。第三方随时可能调整：

- 账户资格和地区可用性；
- 可接受使用方式和自动化政策；
- 模型名称和能力；
- 每日、每月、滚动周期或并发限制；
- 促销期限和订阅权益；
- 价格、优先级和速率限制；
- OAuth、设备码和 API 行为。

Potluck 仪表盘可以显示用量和估算成本，但这些数据不是账单，也可能无法覆盖第三方的全部计费
规则。发送大量请求前，请检查提供商最新的服务条款、账户后台和账单页面。

## 连接符合条件的账户

1. 打开 **仪表盘 → 提供商**。
2. 选择你有权使用的提供商。
3. 按 Potluck 显示的流程完成 API Key、OAuth 或设备码认证。
4. 确认连接状态。
5. 使用仪表盘模型选择器或查询 `/v1/models`。
6. 发送一个不含敏感信息的小型测试请求。
7. 检查提供商自己的用量或账单页面。

具体提供商列表和模型标识可能随 Potluck 版本及账户权限变化。不要照抄旧文档中的模型 ID：

```bash
curl http://localhost:20127/v1/models \
  -H "Authorization: Bearer YOUR_POTLUCK_API_KEY"
```

## 在路由中使用

免费或促销来源可以像其他合格来源一样加入组合或路由配置。加入前应当：

- 单独验证该来源能够正常请求；
- 确认模型适合目标请求类型；
- 明确哪些失败条件允许切换；
- 不要假设名称相近的模型具有完全相同的行为；
- 部署后继续观察第三方的额度和账单。

故障切换可以提高可用性，但不能创造额度、绕过第三方限制或保证请求一定成功。

## 运行注意事项

### 服务条款与账户安全

仅使用你有权使用的账户和凭据。Potluck 不会让原本违反服务条款的用法变得合规。高强度自动化
可能根据第三方规则触发限流、凭据撤销或账户封禁。

### 隐私

请求会发送给实际选中的第三方提供商。发送源代码、个人数据、凭据或机密资料前，应审查对方的
数据处理条款。除非确有调试需要，否则不要启用请求正文日志，并妥善保护 Potluck 数据目录和
备份。

### 可靠性

免费或促销访问可能优先级较低、限制更小，也可能发生模型变更或服务中断。请只用于可靠性要求
与之匹配的工作负载。重要工作负载应配置多个经过独立验证的来源，并保留直接恢复路径。

### 成本

“目前没有观察到收费”不等于“保证免费”。提供商可能开始收费、把部分用量移出订阅权益，或对
输入、输出、缓存、工具、图片等能力采用不同计费方式。条件允许时，应在第三方后台设置消费
上限和告警。

## 故障排除

### 授权失败

- 在同一浏览器会话中完成授权流程。
- 确认账户和所在地区符合使用条件。
- 检查系统时间和网络连接。
- 删除失败连接后重试一次。
- 查看提供商当前状态和最新授权文档。

### 找不到文档中出现过的模型

- 刷新提供商连接和模型列表。
- 查询 `/v1/models`。
- 确认该模型是否对当前账户开放。
- 使用当前实例返回的标识，不要继续使用旧示例。

### 请求被限流或拒绝

- 检查响应状态和 Potluck 用量日志。
- 查看提供商自己的额度和账单后台。
- 降低并发量或请求速率。
- 在服务条款允许时切换到另一个经过独立验证的来源。
